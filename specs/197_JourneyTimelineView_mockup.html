Mockup v2 with sample data, current quarter Q3 2026. Each milestone is a labelled row placed at its target quarter — label, status, period, and overdue flag are readable without hover. Rows within a journey follow the stored milestone order (196), dated before undated; undated rows carry a "no date" tag and are never overdue. Journeys are all active ones, grouped by business domain (A–Z), ordered by target period (undated last). Overdue is computed, never persisted. Activating a journey header opens the capability's drawer on the board. The view is URL-addressed like a lens; read-only users see it identically.
